## 🚀 Correr localmente

No requiere instalación. Cloná el repo y abrí `index.html` en tu navegador:

```bash
git clone https://github.com/luanaOstemberg/Autos-Detaling.git
cd Autos-Detaling
```

Abrí `index.html` directamente o usá la extensión **Live Server** de VS Code.
